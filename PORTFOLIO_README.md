# Vigneshwar Lagishetty Portfolio

A responsive, motion-led portfolio built from Vigneshwar's resume.

## Run locally

Use Node.js 22.13 or newer, then run:

```bash
npm install
npm run dev
```

The portfolio content lives in `app/page.tsx`, and the visual system is in `app/globals.css`.

## Included

- Responsive hero and mobile navigation
- Four featured projects
- About, education, skills, and certifications
- Email and phone contact actions
- Downloadable resume at `/vignesh-resume.pdf`
- Reduced-motion accessibility support
